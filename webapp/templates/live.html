Live check

Run the pipeline now, step by step

Runs the real pipeline once for the chosen lake, the same code as the nightly run: it signs in to Google Earth Engine, searches for Sentinel-2 (optical) and Sentinel-1 (radar) images newer than the last stored ones, checks each image against ESA's own Copernicus catalogue, checks the cloud over the lake, downloads, measures the water, calculates the area and the risk score, and saves the result. Each step appears below the moment it finishes, with what it received, what it did and what it produced.

Results go to this laptop's working copy of the database only, never to the published record. New images arrive only every few days, so a check often finds none: the newest stored image is then replayed through the same steps, every card clearly marked Replay, and nothing is written.
